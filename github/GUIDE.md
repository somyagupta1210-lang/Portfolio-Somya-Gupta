# Your GitHub profile, in 3 simple steps

By Ameer Hamza · The H Series · Day 02/30

## 1. Download and copy
Download The H GitHub Starter ZIP. Copy the master prompt from the resource page.

## 2. Let your AI help
Open ChatGPT, Claude or Gemini. Attach the ZIP and paste the prompt. Answer the questions about you. Your AI should personalize the README, banner, links and skills, then show a preview or return files for review. File editing and previews depend on your AI tool and plan.

## 3. Put your version on GitHub
After you approve the preview, ask for the final ZIP. Extract it. On GitHub, create a public repository named exactly the same as your username. For example, username `alex` means repository `alex`, not `alex-profile`. Upload README.md, assets and LICENSE directly into the repository root, then commit. Open your GitHub profile to see it. If you already have that repository, keep a backup and update the existing files.

No hosting account or GitHub Pages setup is required. The AI should guide you through one step at a time.

## Before sharing
- Use your own name and project links.
- Keep only tools you actually use. The bundled tech stack is an example.
- Remove example.com, YOUR-USERNAME, YOUR-REPO and sample email addresses.
- Keep private contact details, passwords and tokens out of public files.
- Keep LICENSE and assets/DEVICON-LICENSE.txt.
- Native follower counts and contribution activity come from GitHub itself.

This kit follows the same visual direction as Ameer’s profile. It is a beginner-friendly starter, not a copy of his personal data or his generated portrait/banner artwork.
