# The H Portfolio community kit

An independently written, MIT-licensed HTML/CSS/JavaScript starter by Ameer Hamza. It uses the same broad cinematic direction as the creator's portfolio, but is a separate implementation. It does not contain code from Sushmita Dasari's Portfolio_series repository, private business source, Ameer Hamza's personal photos, or his contact details.

## Build your portfolio without coding

1. Download the complete repository ZIP and extract it.
2. Open customize.html in Chrome, Edge or Firefox.
3. Enter your information, upload your own portrait, replace the sample projects and add your education.
4. Click the export button. Replace the existing portfolio.config.js with the downloaded file, using that exact filename.
5. Open index.html. Test the intro, all four entry cards, menu, project dialogs and contact buttons.
6. Add a resume PDF inside assets/ and set its relative path in the customizer if you want a resume link.

If a download is blocked, the customizer also displays the complete generated configuration for copying.

## Use an AI assistant instead

Attach this ZIP or repository and paste MASTER_PROMPT.md. Ask the assistant to collect your details before editing. The model needs the actual files, not just a link it cannot access.

## Put your own copy on GitHub

1. Sign in to GitHub and create a new repository. Suggested name: my-portfolio. Choose Public if you intend the code to be public.
2. Use Add file > Upload files. Upload the CONTENTS of this extracted folder so index.html is at the repository root. Do not upload the ZIP as the only file.
3. Commit the files. Open Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for the deployment to finish. Copy the URL GitHub displays. Verify it on a phone and a desktop.

For a template-enabled source repository, you can use Use this template > Create a new repository instead of uploading files. Existing template copies do not automatically receive later changes from the source.

Never guess your deployment URL or assume that a repository URL is the same as the website URL. If Pages is unavailable, check the repository plan and organization restrictions or use another static host. There is no build step or database in this starter.

## What belongs in your public copy

Use your own public name, original portrait and genuine projects. The included FlowDesk, SignalKit and RelayFlow pages are working browser demos, not paying-client proof. Keep their demo labels if you retain them. Your complete config, images and links are public after hosting. Do not include passwords, API keys, customer records or private financial screenshots.
